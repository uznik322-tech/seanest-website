# Вторичная недвижимость

Блок `resale` в `index.html`: четыре карточки, две колонки от 768 px, одна колонка на телефоне. Характеристики и цены предоставлены пользователем; расчёты доходности и ипотечных платежей не публикуются.

Используемые WebP-обложки подготовлены из исходных фотографий без увеличения разрешения, ширина до 800 px:

| Объект | Обложка | Исходное фото |
|---|---|---|
| White Sails | white-sails.webp | photo_9_2026-10-26_14-34-33.jpg |
| BST | bst.webp | photo_10_2026-10-26_14-35-54.jpg |
| Rainbow | rainbow.webp | photo_3_2026-10-26_14-38-03.jpg |
| STEPS | steps.webp | photo_3_2026-10-26_14-38-59.jpg |

Исходные JPG и служебный обзорный лист удалены с разрешения пользователя. В таблице сохранены имена источников для справки. Карточки используют четыре оптимизированные WebP-обложки. Кнопка «Узнать подробнее» передаёт выбранный объект в форму заявки.

`content.json` — справочник согласованных текстов и выбора фотографий. Страница статическая, поэтому при изменении характеристик нужно также обновлять HTML.
