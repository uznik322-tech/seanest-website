# SeaNest

Статический сайт на HTML, CSS и JavaScript без библиотек и сборки. Для просмотра откройте `index.html` в браузере. Подключение к интернету нужно только для переходов в мессенджеры и социальные сети.

## Файлы

- `index.html` — лендинг.
- `privacy.html` — политика конфиденциальности.
- `css/style.css` — оформление и адаптивность.
- `js/main.js` — меню, выбор объекта, проверка формы и подготовка сообщения.
- `images/logo.svg` — оригинальный знак SeaNest, встроенный в SVG и окрашенный под тёмный фон; исходник сохранён в `logo-original.png`.
- `images/hero.webp` — оптимизированное изображение Alliance Centropolis.
- `images/properties/` — реальные изображения четырёх проектов.

## Отправка заявки

Жёлтая кнопка формы после проверки полей сразу открывает WhatsApp с подготовленным сообщением в этой же вкладке. Дополнительное нажатие на ссылку не требуется. Пользователь подтверждает отправку в мессенджере; сайт не отправляет сообщение самостоятельно.

Серверный обработчик не подключён. Если потребуется принимать заявки напрямую, место подключения API отмечено русским комментарием в `js/main.js`. Секретные ключи должны храниться на сервере. После подключения обработчика обновите политику конфиденциальности в соответствии с фактической обработкой данных.
